# Burhan 1.3.0 — version code 5

- Default-off Expanded inspection models switch in the shared Camera & Capture settings.
- Three optional inspection families with 30 checks: five model-backed experimental checks and 25 guided manual checks.
- Bundled PHELE SSDLite320, SDNET v2 YOLOv8n512 and wall-stain SSDLite320; original models retained.
- Native/browser SSDLite output handling, variable-size YOLO decoding, category filtering and stale-result cancellation.
- Capture-time analysis uses the retained photograph. Evidence/report provenance survives zero detections, backup and restoration.
- Optional inspector-entered tile measurements; reports retain their origin as physical readings entered by the inspector.
- Capability-aware Codex/AWS planning, with older clients retaining the previous catalogue.
- Updated offline HTML design guide and editable designer kit showing the delivered expansion.

Package `com.burhan.site`, arm64-v8a, minimum Android 12/API31 and existing debug signing identity are retained. This prototype APK is for testing. New checkpoints remain experimental; no expanded category has been promoted as a qualified inspection detector.
