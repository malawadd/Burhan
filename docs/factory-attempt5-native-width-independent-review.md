## Geometry and actual labels

The [E sampler](C:/Users/IAM/Documents/hackathon/opencv/project1/scripts/train_factory_round3g.py) takes an actual640-high by512-wide slice of the shared512x1280 source projection. It crops the full original projected mask using exactly the image slice, including hard-location and unbiased crops. Widening therefore retains all labeled defects that lie in the selected source rows; it does not keep an obsolete narrow-ROI label or declare nonselected defects normal. Only image values receive contrast, brightness and optional mild blur. Image and mask receive identical180-degree turns/horizontal flips; there is no crop resize or90-degree transpose.

Positive SDD1 sampling selects a true positive TRAIN pixel, then shifts the vertical crop center by at most192 pixels. The TRAIN-only report says all33 component bbox heights are <=120 pixels and widths <=452. Even if the selected pixel is at a component's endpoint, the farthest opposite pixel is <=119+192=311 pixels from the chosen center, inside the320-pixel half-height. Clamping the crop to source bounds cannot clip an in-bounds selected component. Full512 width contains all reported widths. This is a selected **SDD1 TRAIN component** retention argument; it does not imply every disconnected annotation in the image or every SDD2 component fits vertically. Hard/unbiased crops can legitimately truncate objects at their vertical crop bounds while retaining their correct visible masks.

The five-step schedule is positive/positive/hard/unbiased/SDD2 rehearsal. Rehearsal alternates actual positive and actual normal FIT records; normal targets come from their real all-zero publisher masks.
