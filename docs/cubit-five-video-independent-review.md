# Independent static review of five CUBIT development videos

The exporter and its source/annotation/scoring/panel/replay helpers were reviewed without running inference, encoding, loading source pixels or executing the exporter. No material blocker was found.

The whitelist contains exactly the four sources fixed before the author model's NN evaluation plus the separately declared historical post-hoc spalling76 example. All are development illustrations with no independent accuracy credit. Source files are hash-pinned; loaders use the complete original camera exposures and publisher timestamp association. Lossless replay is checked against raw pixels and original microsecond timestamps before inference, and final annotated video frame count/PTS are decoded and checked exactly. The exporter cannot silently overwrite an existing case attempt/media/report.

The model receives the full raw native image through the normal construction profile. Shared low-light gain is applied once; independently computed displayed native input/gain must match the profile metric and cached raw/native hashes. No publisher box or pixel is passed into inference. Separate panes show RAW, actual gained native input, external publisher boxes and actual model masks/boxes. Matched colors depend on external evaluation, but model foreground pixels come from the actual decoded prototype mask. Packed-bit native masks, shapes and hashes are saved per prediction/frame. Empty masks remain visible/countable and a box hit is explicitly distinguished from mask evidence.

Only the candidate model is instantiated. BEFORE reports are source/model/cutoff/frame/raw/gain/annotation matched and their existing predictions are re-scored; no extra BEFORE NN or media is created. Scoring remains class-aware one-to-one box IoU≥.50. Unlabelled exposures are unscored; unmatched boxes are not verified material false alarms under incomplete publisher annotation scope. No pixel-GT accuracy, physical crack width, structural severity, code acceptance or production qualification is claimed. Failed calibration remains failed in video/report labels.

Optional defensive checks suggested before freezing: assert captured/scored prediction counts agree and masks have native H×W before pairing by order; initialize the fixed-preview variable and require a publisher-annotated first preview for each declared source. The current two-class decoder/order and fixed annotated sources make these expected conditions; this review found no actual mismatch. Root and the construction owner retain source/export ownership and execution authorization.
