# Construction finishes expansion: measured support and remaining work

20 October 2026. This is a source/data/model study and implementation record for wall dampness, paint defects, uneven finishes, cracked ceramics and installation faults. **Those tasks are not all working detectors.** The eight existing crack/material-loss development videos and their failed-model reports remain unchanged. No still-photo collection is represented as a recorded video. No result establishes Saudi Building Code compliance, hidden condition, physical severity or project acceptance.

## What the installed models actually know

The existing DACL adapter exposes these 14 condition channels: crack, alligator crack, wetspot, efflorescence, rust, rockpocket, inspector-marked hollow-area boundary, cavity, spalling/material loss, graffiti, weathering, residual formwork, exposed rebar and combined surface-loss/erosion appearance. Its other five channels describe components and are not automatically faults. Source: [dataset-author toolkit](https://github.com/phiyodr/dacl10k-toolkit), [author class descriptions](https://arxiv.org/html/2309.00460v1).

Relevant existing measurements are from **55 real public-validation photographs**, not moving video or untouched site-independent testing. Checkpoint training/selection overlap is unknown. Full results remain in `output/evaluation/construction-dacl19-round3/512/report.json`.

|---|---|---|---|
| Wetspot | 18.4% / 57.8% / 16.2% | 4 / 45 / 6 | Weak visible wet/stained-appearance candidate; 17/46 class-absent photos flagged. |
| Efflorescence | 67.6% / 43.3% / 35.9% | 6 / 40 / 43 | Visible salt-like deposit candidate; neither active leakage nor moisture quantity. |
| Spalling/material loss | 69.9% / 34.5% / 30.0% | 12 / 71 / 89 | Does not automatically identify whether the lost material is paint, render, masonry or concrete. |

DACL512 measured only 2.43 mask-adapter calls/s in the previous bounded laptop test; it remains a slow photo-review model. Its dataset is CC BY-NC4.0 and its released checkpoint has no separately established redistribution license. Availability of a channel is not solved accuracy. The `hollowareas` class is a **chalk/crayon boundary drawn after sounding**, not camera detection of a hidden void. The `washout` alias covers combined erosion/corrosion appearance, not an established mechanism.

## Actual new tile data and working local specialist

The [manufacturer's MVTec AD release](https://www.mvtec.com/research-teaching/datasets/mvtec-ad) provides industrial anomaly photographs and pixel masks under **CC BY-NC-SA4.0**. Acquisition used a pinned [MMAD research-author mirror](https://huggingface.co/datasets/jiang-cc/MMAD/tree/74db7cacf256eb62b5ce87094f83e9201fb7ac0a/MVTec-AD/tile), retaining the manufacturer terms. Every original file was checked against mirror LFS SHA256 and byte size; an independent full manufacturer-archive checksum was not established.

Acquired **175 real photos and 84 masks**. The mirror exposes 58 original normal-training PNGs, rather than the manufacturer's complete normal-training set. Before reading pixels or running a model, a fixed hash order allocated **48 normal photos to fitting and 10 to normal-only calibration**. All **117 original tile test photos**, including all 17 crack examples and 33 normal examples, were retained. Captions/derivative files were excluded. Asset manifest SHA256: `a89fd18356f54397065ab61d1fe131ebe6e0ae52661c9fca5dca92a3728ef582`.

`edge_runtime/profiles/construction_tile.py` implements a local ONNX-CPU normal-texture nearest-patch model. A safely loaded existing official MobileNetV3-small ImageNet checkpoint supplies early layers 0/3. Input is BGR uint8 resized to 256 with INTER_AREA; RGB/ImageNet normalization is inside the encoder. Forty feature channels at 32×32 are standardized using fitting photos only. A fixed seed selects 1,024 normal descriptors. Exact nearest-normal distance is smoothed on the grid and projected to native pixels. This is a deliberately small, separately measured research candidate, not an implementation of a published PatchCore score.

The threshold was frozen to the 95th percentile of **ten normal-calibration image maxima** before any test decode/inference. Original test masks never enter inference. Torch versus actual CPU ONNX features were checked on a training photo. All original images and masks remain unchanged. The fitter/evaluator completed locally using one CPU thread, overlapping other accuracy work; incidental elapsed times are not speed qualification.
