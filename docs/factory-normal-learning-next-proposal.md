## Primary-source findings

[EfficientAD's paper](https://arxiv.org/abs/2303.14535) describes normal-only student–teacher learning with a separate autoencoder for global anomalies. Its [published architecture/algorithm](https://arxiv.org/html/2303.14535v3) uses dense128/256-channel PDNs,384 teacher outputs,768 student outputs,256-square input and70,000 normal-training iterations. Reported millisecond latency uses an RTX A6000, not this UHD620 laptop. A global256-square reduction of our1280×512 input would reduce the vertical sampling fivefold; preserving native geometry through overlapping tiles costs multiple forwards. Neither option presently proves15FPS with thin-defect localization.

[Anomalib's maintained implementation](https://raw.githubusercontent.com/open-edge-platform/anomalib/main/src/anomalib/models/image/efficient_ad/torch_model.py) provides Apache-2.0 PDN/student/autoencoder code. Its introductory wording calls the teacher EfficientNet, but the actual instantiated classes are `SmallPatchDescriptionNetwork`/`MediumPatchDescriptionNetwork`; architecture selection must follow code. The [weight setup](https://raw.githubusercontent.com/open-edge-platform/anomalib/main/src/anomalib/models/image/efficient_ad/lightning_model.py) points to a public release ZIP, SHA-256 `c09aeaa2b33f244b3261a5efdaeae8f8284a949470a4c5a526c61275fe62684a`, and uses tensor-only state loading. Availability of that teacher does not provide a trained Kolektor student, local latency, or independently established weight redistribution rights. No ZIP was downloaded here. The `nelson1425` and `rximg` GitHub repositories explicitly describe themselves as unofficial and are not treated as the authors' implementation.

[STFPM's authors](https://arxiv.org/abs/2103.04257) learn a normal-only student from a frozen pretrained teacher and compare their feature pyramids for localization. Their [official repository](https://github.com/gdwang08/STFPM) is GPL-3.0 and lists category-specific trained assets; MVTec category weights do not establish Kolektor performance. A separate [Apache-2.0 implementation](https://raw.githubusercontent.com/open-edge-platform/anomalib/main/src/anomalib/models/image/stfpm/torch_model.py) confirms a pretrained frozen teacher and a student trained from scratch. A MobileNet adaptation must be identified as our adaptation rather than the published ResNet experiment.

[PaDiM](https://arxiv.org/abs/2011.08785) models correlations across several pretrained feature levels with spatial Gaussian distributions. [PatchCore's authors' implementation](https://github.com/amazon-science/patchcore-inspection) retains normal patch features in a coreset and performs nearest-neighbor anomaly localization. Both are materially richer than a first16-channel column-normal Gaussian, but dense per-position covariance or large nearest-neighbor banks add memory/query costs. They remain credible alternatives after an actual local preflight, not verified replacements. No author AUROC is converted into defect recall or box/mask IoU at our operating point.

## Recommended bounded next architecture preflight

Prepare a **standalone MobileNetV3-Small feature-pyramid student–teacher**. Do not fuse it with C or reuse any previous density bank. The existing safely loaded official ImageNet checkpoint supplies only the frozen teacher; initialize the separate student from the protected random seed. Tap encoder blocks0,3,6 (16/24/40 channels, different spatial scales), retain the full1280×512 BGR input, and return one640×256 spatial anomaly map. The backbone is deliberately small; the benefit hypothesis is learning nonlinear normal structure across scales instead of assigning anomalies from first-layer density.

At each scale normalize feature vectors and compute bounded channel-wise squared disagreement. Resize the lower-resolution disagreement maps to the fine640×256 grid. Use a single fixed geometric mean, implemented with bounded log arithmetic to prevent half-precision product underflow. This is a proposed adaptation, not an assertion that a coarse feature map can resolve subpixel cracks. The first-scale features preserve finer sampling; deeper scales contribute context and may also suppress real small defects. No raw-pixel shortcut, ROI, mask OR, original-comparison component, filename rule, simulator or defect insertion enters the graph.

Before any normal-only optimization, require a newly exported **nonconstant complete two-encoder graph** and a root-authorized project-quiescent preflight:16 fixed original TRAIN sources,4 warmups then64 complete FactoryProfile calls, all tails retained, serial mean≥15 calls/s, no abstain/skipped graph, original initialization reported. No quality metric is computed in the speed probe. Run a fixed real TRAIN input plus zero through Torch and actual OpenVINO GPU, checking finite maps, shape/alignment, and absolute score error≤.01. The complete dummy/student graph must remain data-dependent; a zero or identity student cannot qualify speed. If either capacity or numeric guard fails, stop before fitting and keep the first failed receipt. No automatic reduced input size or lighter substitute is allowed after observing the result.

The exact preflight source files, teacher SHA, student seed, normalization epsilon, log floor, geometry and selected source identities must be pinned in a new-prefix protocol before export. The prepared design alone authorizes no NN run. A later fit protocol must separately freeze the optimizer/BN policy, fixed checkpoints and source checks before its first update. In particular, do not initialize student equal to teacher (zero loss/anomaly at initialization), do not let teacher BN update, and save each student's actual BN state for deployment. Fresh random student BN needs a declared normal-training policy; this is not inherited from the earlier segmentation trainer by accident.
