# Factory original-mask evidence: every defect and false alarm

The final spatial model was frozen using calibration before this reused 80-view development comparison. All 11 defective views and all flagged normal views are included below. These are original real images, with separate source-resolution model/publisher PNG masks. JPEG panels are display-scaled; numeric scores use original-resolution masks.

Panels show raw input, publisher GT in cyan, model mask in amber, and TP green / FN red / FP amber. A visible model box alone does not count as defect localization.

Image/mask source: [official KolektorSDD, VICOS](https://www.vicos.si/resources/kolektorsdd/), CC BY-NC-SA 4.0. Model/error overlays are local derived visualizations. Commercial use is not cleared by this benchmark.
