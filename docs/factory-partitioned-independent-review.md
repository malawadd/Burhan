# Split feature/score architecture: independent static and arithmetic review

L9 is a new architecture boundary: GPU inference returns only the fixed raw teacher/student block0/3/6 outputs, while a NumPy float32 head implements the existing unit normalization, disagreement, half-pixel interpolation and geometric mean. This is not a demonstrated cause or repair of the earlier GPU kernel discrepancy. Its own end-to-end numerical and complete-profile performance gates remain mandatory.

Independent source review finds no material blocker. Deterministic ancestor extraction keeps original serialized retained nodes, initializers, input and opset bytes; preprocessing remains inside that graph. The fixed six output names/order/shapes/types are validated. Shared request feature views remain live during a synchronous non-inplace CPU computation, and the returned score owns its memory. Existing prediction/warmup/component policy is inherited, with a process-local constructor override restored afterward. Every measured profile call includes GPU request/framework handling, CPU head and postprocessing; request wall time is not a GPU-kernel event timer.

The independent file `tests/test_factory_stfpm_partition_independent.py` adds five tiny arithmetic tests against the original Torch `unit_feature`, `disagreement` and `F.interpolate(align_corners=False)` functions. Cases include zero/subnormal/near-floor/high-finite features, squared-denominator floor boundaries, identical/opposite/random feature pairs, odd up/down interpolation and degenerate edges, complete three-level score composition, input immutability and owned output. All five pass in.052s at absolute/relative2e-6 tolerance. Total command walltime9.38s includes Torch imports. No model constructor, checkpoint loading, graph/network forward, source pixel decode or performance benchmark runs in these tests.

Passing small arithmetic fixtures does not establish full GPU numerical parity or speed. The single declared GPU/f16/no-Winograd/raw-six architecture must pass the fixed three end-to-end references at≤.01, finite/bounded/nonconstant output, then the first quiet64 complete-profile calls at≥15. A future learned correction is blocked until those gates and a separate coordinator release; it must apply the same transform to all200/400/600 L7 sources and preserve their rejection artifacts, with all-three numeric-fail/no-CAL or complete-CAL outcomes before ranking. Original comparison scoring remains coordinator-only and final fitted capacity/sustained runtime remain required.
