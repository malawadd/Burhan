## Data and native detail path

The protected attempt3C protocol has30 original SDD1 fitting items,10 calibration items and10 exposed comparison items; metadata-only set checks found zero pairwise overlaps. The SDD2 split file matches its protected SHA256, contains1,865 inner-fit records and466 reserved calibration records, and all fitting image paths belong to the official `train` directory. Training samples the inner-fit list only. No comparison filename, known miss identifier, or test-specific inference rule appears in the inspected active training/serving code. Hard-negative locations are looked up only against enumerated original fitting image keys; the matcher requires at least one real matching training location.

The inherited `training_rows` and `FullResolutionSdd2.get` project original binary annotations **directly** to512×1280 using floating `INTER_AREA >0`. They do not first pool to the old stride-two grid. `make_batch`/`sdd2_batch` preserve the target's full patch geometry, crop frame and mask together, and flip both together. The C loop calls `sensitivity_loss(model(image),target)` without stride-two target pooling. Thus the packed four-phase residual is supervised at full resized-input resolution. This is512×1280 analysis input, not a claim to preserve every original sensor pixel.

`PackedPixelRefiner` concatenates12 half-grid learned feature channels with8 pixel-unshuffled gray/local-contrast channels; its4 output phases are pixel-shuffled back to input resolution and added to upsampled context logits. No annotation enters `forward`. C changes serving through an explicit `MaxPool2d(2)` wrapper after this learned full-resolution output. The protected protocol correctly predeclares training `[1,1,1280,512]` and serving `[1,1,640,256]`. Maximum logits commute with monotonic sigmoid, but this deliberately changes output localization granularity; the docs correctly do not claim full-resolution serving masks or equivalence to B.

## Calibration, actual serving and independent evidence

Calibration reads only the original calibration item list, derives `original_pixel_weights` from each actual score-map shape, and counts nearest-projected cells against original masks. It uses the same seed area, largest20 seed cap, optional connected lower-threshold growth and final area units as serving. Scores are not boosted with GT, dilated validation masks or filename rules. Original masks remain unchanged. The fixed final ordering in `point_rank(...,True)` and `freeze_factory_round3e.rank` agrees with the seven-field protected rank; all three planned checkpoint steps200/400/600 must be present before freezing. Hash/policy checks bind the selected ONNX and metadata; the freeze preserves previous attempt-freeze hashes and explicitly retains exposed-development scope.

`FactorySegmentation` accepts the old640×256 and full1280×512 score grids, then derives source-coordinate boxes from actual `scores.shape` and actual source-frame width/height. Left/top use floor, right/bottom use ceil and clipping, covering the selected source projection without reverting to hardcoded stride-two dimensions. The actual C output uses the old grid intentionally. The profile's existing quality/aspect checks still apply; a raw calibration timing is not complete-runtime capacity evidence.

The independent audit invokes `FactoryProfile.process`, captures actual model scores, independently reconstructs the frozen component/growth mask and returns it to original annotation resolution. Quality/aspect abstentions become zero predictions and remain misses for defective-view recall. Its source-mask P/R/IoU remains primary. Supplementary `runtime_box_metrics` consumes the **actual emitted finding boxes** and matches them against connected-component boxes derived from original GT masks; it does not replace pixel masks or invent true publisher box annotations. A correctly overlapping box can score well while its pixel mask scores poorly, so both outputs must remain visible. All defective views and flagged normals are saved when visual evidence is requested.

## Actionable guard/wording findings

1. **Bind the actually loaded warmstart to the protected source hash.** `train_factory_round3c.main` records a hardcoded step400 `.pt`, whereas `initialize()` resolves the `.pt` from the current attempt2 frozen winner. The code verifies that winner's ONNX hash, but not that the loaded state-dict path/hash equals the protected protocol's warmstart path/hash. A future changed winner or changed `.pt` could make the provenance statement inaccurate while loading successfully. The current winner is step400 and both actual path and state-dict SHA256 match the protected protocol (`2d965333765624b460522f23bc52f8c5092e2b30af3a985ab154f1df4c5e4bc3`), so this is a hardening gap, not observed contamination. Resolve the source once and assert exact path/hash before loading; no retraining is implied for the verified current identity.

2. **Describe the seed-stage guard precisely.** The raw seed shortlist filters `normal_fp<=1` only, picks one area per high threshold and keeps the top6 highs. Foreground precision≥.65 is applied to final grown policies. The final candidate guard/ranking is correctly enforced, but the phrase “best eligible area” could be read as applying both guards at the raw seed stage. This is a predeclared heuristic search, not exhaustive optimization over every high/area/growth combination. Clarify the wording and preserve this run's actual search; do not silently change the search after viewing comparison results.

3. **Optional cache provenance improvement for later experiments.** Existing calibration caches bind to the ONNX hash and verify image order/defective flags. They do not include image/mask file hashes, the grid shape contract or a complete preprocessing/cache-code identity. A changed calibration mask retaining the same boolean class would be accepted by a reused score cache. There is no observed current mismatch, and the cache contains calibration only. Future caches should save exact source image/mask hashes and expected output shape, then fail closed on drift. This is about reproducibility, not evidence that reserved data were fitted.

No result from this static review qualifies≥15FPS, establishes blind-test accuracy, or resolves manufacturing suitability. The trained winner still needs the coordinator's frozen-policy independent localization audit and final isolated paired capacity/sustained-runtime measurements. The preflight's14.9708/s is explicitly below15/s in the existing report and is not credited as a pass.
