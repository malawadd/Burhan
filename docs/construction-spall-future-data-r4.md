# Separate future spalling-data experiment

20 October 2026. This is a distinct **data acquisition and review proposal**, not a change to the active construction fit, calibration, heldout, thresholds or UI. The original capture-folder exclusions remain intact for already-started experiments. The coordinator explicitly authorized investigating a future version using other spall IDs from dset1/2, while treating the old exposed clips as development evidence only.

Before any source payload download, `datasets/construction/evcivil-spall-future-r4/protocol-before-acquisition.json` froze the exact source membership, exclusions, metadata ordering, timestamp rule and use limitations. Source: [official ev-CIVIL release](https://doi.org/10.11583/DTU.25924228), **CC BY4.0**. This note records the plan while acquisition is in progress; measured acquisition/duplicate/pixel-review outcomes will be appended afterward.

All existing fit/calibration/heldout canonical IDs, aliases and exposed crack10/crack89/spall35 remain excluded. Entire dset5/dset6, Nov18 calibration and Jan2 heldout capture groups are excluded, including otherwise unused IDs. The new data remain under their own `evcivil-spall-future-r4` root, without an active training YAML. Different numeric IDs are not proof of different physical defects or independent projects.

Original ZIP member sizes/CRC32 and actual source SHA256 values will be verified. Camera exposures are associated only with the shared publisher first-at-or-after timestamp rule, bounded by median camera period/2+1000microseconds. At most24 uniformly selected qualified original exposures per sequence are preserved; each must contain a publisher spall target, while all in-view publisher crack/spall boxes remain. Full original H5/NPY sources, camera frame indices, original timestamps and relative source PTS remain available. Unannotated exposures are not manufactured into healthy negatives. No neural inference, synthesized damage, photo slideshow or video encoding is part of this acquisition.

Duplicate screening will compare selected real exposures against existing fitting/calibration/heldout images and known exposed-source camera frames, using exact pixel hashes and conservative non-neural scene similarity. Similarity flags need visual review; smooth concrete walls can cause false similarity, and metadata or hashes cannot prove project independence. A source with an uncertain reserved-scene match cannot be cleared merely because its filename differs. This review uses no model predictions or heldout accuracy to choose favorable examples.

If a later model uses these assets, it must be a new experiment with frozen provenance before fitting. The original exposed-domain clips cannot provide independent validation for that model. Prefer reserving entire additional capture sessions/projects for future evaluation; existing dset5/dset6 and night evaluation groups stay untouched, with physical-project independence explicitly unverified. Acquisition alone does not demonstrate a working spall detector.

No duplicate was confirmed in that bounded review. **This does not clear every flagged pair or establish independent physical sites**; the flag list remains available for later source-group review.

For a future experiment, keep every frame of each canonical ID/alias together and preserve entire calibration/heldout capture groups. Do not randomly split these288 frames. Treat spalling24/27 as separate substrate strata; a concrete-only detector should report or exclude that scope before fitting, without looking at model outcomes. Do not mix a source into fit and calibration through a renamed alias. A trustworthy additional evaluation should use a genuinely new documented capture/project, rather than reserve a few correlated frames from these same videos. All new assets are still **unused proposed training data**; the active experiment and its heldout inputs are unchanged.

Reproduce acquisition with `scripts/prepare_evcivil_spall_future.py` in the export environment (requires h5py; rerunning intentionally refuses to overwrite a completed manifest).
