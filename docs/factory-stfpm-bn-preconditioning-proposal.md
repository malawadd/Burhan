## Hypothesis and its limits

The initial student has independent random convolution weights and initially unadapted evaluation BN statistics. In ONE fixed normal TRAIN reference, the bounded Torch-half diagnostic found87.78% of deepest student feature values nonzero but below the FP16 normal boundary2^-14. CPU-half scores differed from TorchFP32 by about .0076, while the actual GPU differed by about .095. This supports investigating dynamic-range sensitivity, but does **not** establish that tiny values or GPU subnormal handling caused the mismatch. It is not a population estimate over208 TRAIN views.

Normal-only BN preconditioning is a different, concrete hypothesis: calibrate the student's running statistics on actual normal patterns before exporting, while every convolution/affine weight and the complete teacher stay identical. It could move later-layer activation distributions into a more stable range. It may still fail numerical parity, speed or later defect localization; no expected recall improvement is claimed. No additional GPU configuration search, changed error tolerance or original-comparison tuning belongs to this proposal.
